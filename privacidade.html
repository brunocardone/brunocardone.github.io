Política de Privacidade – Clipper Posting

O Clipper Posting é uma ferramenta interna, usada apenas pelo dono dos canais, para enviar vídeos aos próprios canais do YouTube pela API oficial (YouTube Data API v3).

Dados acessados

Com a autorização do dono da conta, o app lê a identificação do canal (nome e ID) e envia vídeos com título, descrição e tags. Não lê e-mails, contatos, comentários nem dados de outros usuários.

Armazenamento

O token de acesso fica em um cofre de segredos privado e criptografado, acessado só pelo dono. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com → Segurança → Apps de terceiros.

O uso das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google.

Contato

Pelo e-mail de suporte informado na tela de consentimento.
